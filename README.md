# 牛马计时器 · Work Timer

一个把工资"按秒算出来"的小工具：上班打开它，数字就一毛一毛往上涨，下班存档，月底能看到这个月哪天最赚。

纯前端单文件，双击 `index.html` 就能用，不装任何东西，数据只存在你自己的浏览器里。

## 它能做什么

**实时赚钱**
- 大数字按秒滚动：今天已赚、每秒 / 每分钟 / 每小时赚多少
- 点「开始上班」先把「上班时间 → 现在」已挣的钱算出来，再从这个数继续跳
- 距下班倒计时，超时了显示「已超时 00:12:30」，继续算钱不封顶

**四种计薪方式**（v22）
- 月薪 / 日薪 / 时薪 / 年薪（12·13·14·16 薪摊算）
- 自动换算时薪，设置页实时显示推导公式

**发薪周期日历**（v9 起）
- 按发薪日切分周期，例如每月 15 日发薪 → 本期 10-16 ~ 11-15
- 日历标出周末、法定节假日（休）、调休补班（班）
- 点任意一个过去的工作日，可以标记：正常上班 / 休息 / 带薪假 / 病假 60% / 半天班 50% / 上班 80% / 加班 1.5·2·3 倍

**统计**
- 本期构成（v20）：按类型汇总天数与金额，带占比条，合计 = 本期已赚
- 近 6 个月柱状图 + 年度累计 + 出勤天数 + 日均（v23）
- 每天工时与收入明细，可导出 CSV（Excel 直接打开）

**攒钱目标**
- 多个目标，进度条按本期已赚推进，自动估算「还差 N 个工作日 · 约 X 月达成」

**其他**
- 下班提醒：最后 10 分钟浏览器标题变成 `⏰ 5 分钟 · ¥434.20 · 牛马计时器`（v21）
- 深色 / 浅色主题（v24）
- 迷你小窗：`index.html?mini=1` 打开紧凑版，配合 PowerToys `Win+Ctrl+T` 置顶
- 备份：导出 JSON / 导入 JSON（v21），换电脑、清缓存前先导一份

## 怎么用

1. 双击 `index.html`（或访问 GitHub Pages 地址）
2. 第一次打开会弹设置：填工资、每月工作日、上下班时间、午休、发薪日
3. 点「开始上班」，看数字往上涨
4. 下班点「下班存档」
5. 日历上补点过去的日子（请假、加班、半天）

数据全部在浏览器 localStorage，不上传任何服务器。

**注意**：清浏览器缓存会清掉数据，重要的话定期点「导出备份 JSON」。

## 开发

```bash
# 跑测试（140 条断言，无浏览器、假时钟）
node _tests/harness.js
```

结构：

```
index.html          主程序（HTML + CSS + JS 单文件）
_tests/
  app.v8.js         业务逻辑源文件（构建时注入 index.html）
  app.js            注入用副本
  harness.js        测试台：假时钟 + DOM 桩 + localStorage 桩
  ids.json          DOM id 清单
```

改逻辑的流程：改 `_tests/app.v8.js` → 重新注入 `index.html` 的 `<script>` → `node _tests/harness.js` 全绿 → 交付。
