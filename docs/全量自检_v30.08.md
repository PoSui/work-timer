## 三、自检过程中发现并处理的真实问题

1. **6 个悬空 id**：`sumTag/rankWrap/detailBody/rankBody/rankTag/mMode` 在 HTML 中不存在。均为 v24 后遗留，代码侧有 if 保护或位于死函数，不崩；已进白名单并写明原因，防止以后被「顺手修复」时误判。
2. **版本一致性初版误报**：起初按「台账最后一行」取版本号，但台账按版本倒序附加，实际末行是历史行 → 改为「台账中出现该版本号即算一致」。
3. **沙箱限制**：`node --check` 与 python 的 `subprocess` 在本会话沙箱里被拒（EPERM / WinError 5），故语法检查改 `new Function`、commit hash 用环境变量传入。
