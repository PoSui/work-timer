# 功能规划 v27 / v28（「爽感」优先）

> 2026-11-04 老板放权：版本号我自己定，功能我自己想，但要**一定有爽感**，并且留测试记录。
> 版本规则：新增功能 = 大版本进位 → **v27、v28**。

## 判断标准：什么叫「爽感」

不是加动画就好。爽感 = **付出 → 立刻看见回报 → 有对比 → 有纪念**。四个来源：

| 来源 | 做法 |
|---|---|
| 实时反馈 | 数字每秒跳、跨整数时闪一下，让"在赚"看得见 |
| 结算时刻 | 下班给一张总结卡：今天赚多少、比昨天多多少、用时多少 |
| 连续性 | 连击天数（连续上班多少天），断了会心疼，所以会来打卡 |
| 可炫耀 | 一键生成分享图/文案，能发给对象、发朋友圈、发群里 |

## v27：爽感基础包（3 个功能）

### A. 数字跳动的仪式感
- 主数字每秒更新时带 120ms 缓动（不要生硬跳变）
- 每跨过一个 **¥10 整数**：数字闪一次（0.2s 高亮 + 极轻微放大 1.02 倍）
- 跨过 **¥100 整数**：额外一次 0.4s 的横向扫光
- 设置里加「动效」开关（默认开；关掉只剩数字跳动）

### B. 下班结算卡
- 点「下班存档」后弹出结算卡（不是 alert）：
  - 今天赚 **¥XXX.XX**（大数字）
  - 用时 **XhYYm**，平均每小时 **¥XX.XX**
  - 对比：**比昨天多 ¥X.XX（↑12%）** / 比昨天少 / 昨天没记录
  - 一行大字情绪文案，按结果分档：破纪录「今天是你赚得最多的一天」、超过昨日「比昨天多赚了一顿午饭」、普通「今天也稳稳赚到了」
- 底部两个按钮：「复制战绩」（复制成一段文字到剪贴板，含金额/用时/连击天数）、「关闭」
- 复制文案示例：`今天上班 7h00m，赚了 ¥450.57，连续第 12 天。牛马计时器`

### C. 连击天数（streak）
- 定义：含今天的连续有记录工作日天数（周末/法定假不计入、也不打断）
- 显示位置：主界面顶部状态旁一枚小徽章 `🔥 连续 12 天`；结算卡里也显示
- 断连：昨天（上一个工作日）没记录 → 从 1 重新开始

## v28：成就与分享（3 个功能）

### D. 里程碑徽章墙
- 徽章：首日 ¥1、累计 ¥1,000、¥5,000、¥10,000、¥50,000；连击 7 天、30 天、100 天
- 达成瞬间：右上角滑入徽章 + 轻微音效开关联动（默认静音）
- 徽章墙：主界面一张卡片，已解锁彩色、未解锁灰色并显示「还差 ¥X」
- 持久化：存 localStorage（`niuma.badges.v1`），不随清空记录丢失（除非清空全部）

### E. 月度热力图
- 当月按天渲染 30/31 格，颜色按当天金额分 4 档（0 / <50% 日薪 / 50–100% / >100%）
- 悬停（或小窗）显示「11-14 · ¥450.57」
- 与日历并存：日历管"标记状态"，热力图管"一眼看强度"

### F. 分享图
- 点「生成分享图」→ canvas 画一张 600×400 PNG（浅色渐变底、大金额、本月累计、连击天数、日期）→ 直接下载
- 不引入任何第三方库（手写 canvas）
- 图上带一句签名：`牛马计时器 · 今天也在赚`

## 验收标准（pm 按此验收）

- 每个功能都要有断言（改前必红）
- 动效类无法自动测的，断言"状态位/类名切换"（如 `body.flash` 加上又移除）
- 结算卡与徽章的数据必须与主界面口径一致（同一个 `dayValue`/`periodTotal`）
- 分享图/热力图不得引入外部依赖
