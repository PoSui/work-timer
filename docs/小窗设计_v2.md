# 小窗设计 v2（`?mini=1` / `?mini=2`）

> 用途：给开发（java-dev / lead）实现「挂在桌面角落的赚钱计数器」的设计规格。**本文只做设计，不改代码。**
> 基线：v26.02（`index.html` 1,288 行 / `_tests/app.v8.js` 947 行）。现状小窗是 430×380 的"缩小版大窗"：顶部四个控件抢视线、三栏等宽卡片把「时薪/每分钟/每秒」挤成三行、只显示今天进度、主数字被周围文字稀释。
> 本设计**只改小窗模式（`?mini=1` / `?mini=2`）**；大窗版式、计时口径、存储结构一律不动。

## 1. 设计目标

**一句话**：小窗是"贴在桌面角落的计数器"，不是缩小版首页——**眼睛扫 0.5 秒，只回答两个问题：今天赚了多少？这一秒还在不在赚？**

### 1.1 一眼必须看到（优先级 1）

- **今天已赚**（大数字，2 位小数，工作中每秒跳动）。
- **每秒在赚多少**（`每秒 +¥0.0179`，让"正在赚"有速度感，这是 v1 最缺的一口气）。

### 1.2 一眼顺带看到（优先级 2）

- 状态（工作中 / 已下班 / 未开始，用 8px 状态点 + 主数字颜色表达）。
- 距下班倒计时；超时后换成"已超时 00:12:30"。

### 1.3 需要时能瞥到（优先级 3）

- 今天进度百分比、还差多少；标准窗额外给"本期已赚"和"有效工时/日工时"。

### 1.4 明确不看（小窗里一律不要）

- 设置项、日历、目标、构成统计、6 个月趋势、主题切换、导出/备份。
- 「小窗」按钮本身（v1 重复开窗的根源）、品牌名、空格提示、三个大操作按钮。
- 目标/图表/广告位一律不做——小窗只负责"看"，操作只保留最低限度。

### 1.5 设计立场

- **信息做减法，字号做乘法**：主数字 42–56px，其余全部 ≤12px；靠尺寸和颜色分主次，不靠卡片边框。
- **不制造"假置顶"**：浏览器无法常驻置顶，只在首次进入时提示一次 PowerToys 快捷键，不画假的置顶按钮。
- **不确定的钱不显示**：未设置月薪时主数字显示 `—`，不显示 ¥0.00 假装算得出来。

## 2. 布局线框（ASCII，标优先级）

### 方案 A：迷你条 360×120（默认，挂桌面角落/副屏边）

```
┌──────────────────────────────────────────────┐ 360 × 120
│ ● 今天已赚 · 21.3%                 回大窗     │ ← 14px 行：③状态点+③标签/进度，右 ③回大窗
│                                              │   间距 4
│ ¥96.16                                       │ ← ① 主数字 42px
│                                              │   间距 4
│ 每秒 +¥0.0179 · 距下班 02:13:45              │ ← ② 辅行 12px（金额绿、倒计时灰）
│                                              │   间距 8
│ ▓▓▓▓▓▓▓▓▓▓░░░░░░░░░░░░░░░░░░░░░░░░░░        │ ← ③ 进度条 3px（贴下沿）
└──────────────────────────────────────────────┘
```

- ① 主数字独占一行，左侧对齐；② 辅行承接"速度 + 剩余时间"；③ 标签/进度/进度条/回大窗全部弱化。
- 逻辑分组：**上=状态，中=钱，下=速度与时间**；三行读完不超过 0.5 秒。

### 方案 B：标准小窗 380×240（需要多看一眼进度/本期时）

```
┌──────────────────────────────────────────────┐ 380 × 240
│ ● 工作中                     本期 ¥4,806.13  回大窗 │ ← ③ 状态点+③本期（右）+③回大窗
│                                              │
│ 今天已赚                                      │ ← ③ 标签 10.5px
│ ¥96.16                                       │ ← ① 主数字 56px
│ 每秒 +¥0.0179 · 距下班 02:13:45              │ ← ② 辅行 12.5px
│                                              │
│ 今天进度 21.3%                   还差 ¥354.41 │ ← ③ 11.5px
│ ▓▓▓▓▓▓▓▓▓▓░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░  │ ← ③ 进度条 4px
│ 工作 2h05m / 7h00m                            │ ← ③ 11px（仅标准窗有）
└──────────────────────────────────────────────┘
```

- 标准窗比迷你条多 3 项：右上"本期已赚"、右下"还差多少"、底部"有效工时"。
- 主数字仍独占视觉中心；本期金额用 15px 蓝色，不进主视觉。

## 3. 规格表

### 3.1 窗口与容器

| 项 | 迷你条（mini=1） | 标准窗（mini=2） |
|---|---|---|
| `window.open` 尺寸 | `width=360,height=120` | `width=380,height=240` |
| 窗口选项 | `menubar=no,toolbar=no,location=no,status=no,resizable=no,scrollbars=no` | 同左 |
| 缩放 | 固定，不响应式（内容 100% 宽高，内层最小 336×112 / 348×232 不裁切） | 同左 |
| 页面内边距 | `10px 12px` | `14px 16px` |
| 背景 | 浅色：`linear-gradient(160deg,#dff1ff 0%,#f3f8fc 60%)`；深色：`linear-gradient(160deg,#0e1922,#132330)` | 同左 |
| 卡片/主体 | 无卡片边框，直接铺在背景上（减少一圈"盒子感"）；如必须保留卡片：`#fff`、`1px #e3edf6`、`border-radius:12px`、`box-shadow:0 6px 20px rgba(31,143,224,.10)` | 同左，`radius 14px` |

> 说明：`window.open` 的 width/height 含浏览器窗口边框/标题区，实际内容区会略小（Chrome 约 −8~−30px 高）。规则：**内容按 100% 自适应，不得出现横向滚动；主数字/辅行/进度条必须完整可见**（验收以"无滚动、无裁切"为准，不以像素精确为准）。

### 3.2 字号 / 行高 / 字重

| 元素 | 迷你条 | 标准窗 | 字体/字重/细节 |
|---|---|---|---|
| 主数字 `¥96.16` | 42px / 1.0 | 56px / 1.0 | `"Consolas","Menlo",monospace`，700，`letter-spacing:-1.5px`，`font-variant-numeric:tabular-nums`（跳字不抖） |
| 主数字小数位 | `.dec` 0.55em（沿用现有结构） | 同左 | 2 位小数；`¥0.00` 时用 `#b9c8d6` 灰 |
| 辅行（每秒/倒计时） | 12px / 1.3 | 12.5px / 1.3 | 常规 400；"每秒 +¥0.0179"数字用 `#12a877`，倒计时用 `--mini-dim` |
| 标签（今天已赚/本期已赚） | 10.5px / 1.2 | 10.5px / 1.2 | 500，`letter-spacing:.5px`，`--mini-dim` |
| 次行（进度/还差/工时） | 11px（迷你条只有"· 21.3%"） | 11.5px / 1.2 | 数字 600 用 `#203040`，文字 `--mini-dim` |
| 回大窗 | 11px | 11px | 400，`--mini-dim`；hover `#0b64b0` |
| 置顶提示 | 10.5px | 10.5px | `--mini-dim`，只出现 3 秒 |

| 项 | 值 |
|---|---|
| 纵向节奏 | 行间距 4px；块间距 8px；迷你条总高预算 10+14+4+44+4+16+8+3+10=113 ≤ 120 |
| 进度条 | 高 3px（迷你条）/ 4px（标准窗），圆角 2px，轨道 `#eaf2fa`（深色 `#1d2d3a`），无描边 |
| 状态点 | 视觉 8px 圆；点击热区 24×24（padding 8px）；未开始为空心圆（1.5px 边） |

| 圆角 | 主体 12px（迷你条）/ 14px（标准窗）；进度条 2px；状态点 50% |

## 4. 文案（控制字数、禁止换行）

所有文本容器统一 `white-space:nowrap; overflow:hidden; text-overflow:ellipsis`；金额用 `tabular-nums`。中文按字计、符号按半角宽计，括号内为最大字数。

| 区域 | 迷你条 | 标准窗 | 最大长度/说明 |
|---|---|---|---|
| 标签 | `今天已赚 · 21.3%` | `今天已赚` | 迷你条把进度并入标签（15 字符内），标准窗单独一行标签 |
| 主数字 | `¥96.16` / `¥12,345.67` | 同左 | ≤10 字符；超过 `¥99,999.99` 由 JS 降级 36px（防溢出） |
| 辅行·工作中 | `每秒 +¥0.0179 · 距下班 02:13:45` | 同左 | ≤26 字符；每秒 4 位小数（沿用 `money4`），倒计时 `HH:MM:SS` |
| 辅行·超时 | `每秒 +¥0.0179 · 已超时 00:12:30` | 同左 | ≤26 字符；超时时间用金色 `#f0a02a` |
| 辅行·已下班 | `今天存档 · 2h05m` | `今天已存档 · 作业 2h05m`（≤14 字） | 不再显示每秒，强调"已结账" |
| 次行·进度 | 无（已并入标签） | `今天进度 21.3%` 左 / `还差 ¥354.41` 右 | 各 ≤12 字符，左右两端对齐 |
| 次行·工时 | 无 | `工作 2h05m / 7h00m` | ≤16 字符 |
| 状态点 tooltip | `开始 / 下班 / 继续` | 同左 | `title` 属性，不占版面 |
| 回大窗 | `回大窗` | `回大窗` | 固定 3 字，不加图标（图标会抢视线） |
| 置顶提示 | `Win+Ctrl+T 置顶` | 同左 | ≤12 字符，3 秒淡出 |
| 未设置月薪 | 主数字 `—`；辅行 `回大窗设置月薪` | 同左 | 不显示 `¥0.00`，不显示每秒 |
| 未开始 | 主数字 `¥0.00`；辅行 `点 ● 开始 · 距下班 —` | 同左 | 暗示点状态点可开始 |

**换行红线**：以上任何一条在 360×120 / 380×240 内都不允许出现第二行；长文案优先截断（`…`），不缩字号（缩字号会让主次关系乱掉）。

## 5. 状态矩阵（四种状态 × 全区域）

| 状态 | 判定条件 | 状态点 | 主数字 | 标签 | 辅行 | 进度/次行 | 点状态点 | 回大窗 |
|---|---|---|---|---|---|---|---|---|
| **未设置工资** | `monthlyPay()<=0` | 金色空心 | `—`（灰） | `今天已赚` | `回大窗设置月薪` | 迷你条无；标准窗进度 0%、工时 `0h00m / 0h00m` | 无操作（不弹窗） | 打开大窗并展开设置（`#settings`） |
| **未开始** | 无今日记录且无 ended | 灰色空心 | `¥0.00`（灰） | `今天已赚 · 0.0%` | `点 ● 开始 · 距下班 —` | 迷你条 0%；标准窗 `今天进度 0.0% / 还差 ¥450.57`、`0h00m / 7h00m` | **开始上班**（等价 `startTimer`） | 正常回大窗 |
| **工作中** | 有 `startMs` 且无 `endMs` | 绿色实心 + 呼吸 | 每秒跳动 | `今天已赚 · 21.3%` | `每秒 +¥0.0179 · 距下班 02:13:45`；超时后 `· 已超时 00:12:30` | 进度条按 `dayPct` 增长，填充渐变；标准窗 `还差 ¥354.41`、`工作 2h05m / 7h00m` | 点击 → 确认后**下班存档**（`stopToday`） | 正常回大窗 |
| **今天已下班** | 今日记录有 `endMs` | 琥珀实心（不呼吸） | 冻结金额 | `今天已赚 · 已存档`（迷你条）/`今天已赚`（标准窗） | `今天存档 · 2h05m`（标准窗 `今天已存档 · 作业 2h05m`） | 进度条停在存档值；标准窗保留 `还差`/工时 | 点击 → **继续计时（回滚存档）**，沿用现有 confirm 文案 | 正常回大窗 |

补充两条：

- **切换今天/本期**：任何状态下单击主数字区域，主数字在 `今天已赚 ⇄ 本期已赚` 间切换；标签同步变化（标准窗右上角显示"另一个"数字：主看今天时右上显示本期，反过来亦然）。选择持久化到 `localStorage: niuma.miniView = "today" | "period"`，默认 `today`。
- **金额来源**：今天=`todayEarn()`（2 位小数）；本期=`periodTotal().total`；每秒=`todayRate()/3600`（4 位小数）；进度=`dayPct`；还差=`dayLeft`；工时=`workTxt/workTotal`——全部已有函数，不需要新口径。

## 6. 交互

### 6.1 保留的控件（只有两个）

| 控件 | 位置 | 行为 |
|---|---|---|
| **回大窗** | 右上角，11px 文字 | 先 `window.close()`；若被浏览器拦截（如手动打开的标签页），回退 `location.href=location.pathname`（去掉 query 回主视图）。也响应 `Esc`。 |
| **状态点** | 左上角 8px 圆点（点击热区 24×24） | 唯一主操作，按状态映射：未开始→开始上班；工作中→下班存档（confirm）；已下班→继续计时（confirm）；未设置→不响应。`title` 随状态变（开始/下班/继续）。 |

**移除**：`#btnMini`、`#btnTheme`、`#btnStart/#btnStop/#btnRestart` 三个大按钮、`brand`、`hint`、三个 `chip` 卡片、三条 `.bar-row`（小窗内全部 `display:none`）。小窗里不再有"小窗"按钮，重复开窗问题自然消失。

### 6.2 点击切换今天/本期

- 主数字区域整块可点（`#miniMoney`），单击切换，标签与右上"另一个数字"同步。
- 切换不改变计时状态、不写记录，只写 `niuma.miniView`；刷新后保持。

### 6.3 键盘

- `Esc` = 回大窗（新增监听）。
- `Space` 保留现有全局行为：未开始时开始上班；**不作为停止键**（避免手滑把一天存档了）。输入框场景小窗里不存在。

### 6.4 置顶提示（不做假置顶）

- 浏览器无法让窗口常驻最上层，**不画置顶按钮**。
- 每个浏览器会话首次进入小窗时，在进度条上方右对齐淡入 `Win+Ctrl+T 置顶`，3 秒后淡出（`sessionStorage: niuma.miniTip = "1"` 只提示一次）。
- README/大窗提示里说明用 PowerToys `Win+Ctrl+T` 置顶，小窗本身不实现。

### 6.5 尺寸选择与主题

- `?mini=1` = 迷你条 360×120（默认）；`?mini=2` = 标准窗 380×240。
- 大窗「小窗」按钮默认按设置项 `S.miniSize`（`1`/`2`，默认 `1`）打开；设置区加一个"小窗尺寸"下拉（迷你条/标准窗）——**这是本设计唯一新增的设置项**。
- 主题跟随大窗 `S.theme`，小窗不提供切换按钮；深色用现有 `body.dark` token。

## 7. 验收标准（可测）

1. **尺寸与无滚动**：分别打开 `?mini=1`、`?mini=2`，`window.open` 参数为 `360,120` / `380,240`；页面 `documentElement.scrollWidth <= clientWidth+1`，且主数字、辅行、进度条的 `getBoundingClientRect().bottom <= innerHeight`（无纵向裁切）。两尺寸 × 四状态共 8 组合全部满足。
2. **文字不换行**：主数字、辅行、标签、次行四个文本容器在 8 组合下 `scrollWidth <= clientWidth+1` 且 `white-space:nowrap`；`每秒 +¥0.0179 · 距下班 02:13:45` 与 `还差 ¥354.41` 均单行显示（可在真机 DevTools 里逐项测量，或加一条页面自检脚本打印结果）。
3. **四状态正确**：按第 5 节矩阵逐项核对——未设置时主数字为 `—` 且不显示每秒；未开始 `¥0.00`；工作中主数字每秒变化（10 秒增量≈0.179×倍率，与 harness 第 4 组同口径）；已下班冻结（60 秒不变）。状态点颜色/呼吸动画与状态一致。
4. **控件只剩两个**：mini 模式下可见且可点击的控件只有 `#miniBack` 与 `#miniDot`；`#btnMini`、`#btnTheme`、`#btnStart/#btnStop/#btnRestart` 均不可见；点小窗按钮不再产生新窗口（无 `window.open` 调用）。
5. **交互与持久化**：点状态点在三种状态下分别触发开始/存档/继续（存档与继续弹现有 confirm）；点主数字区域在 今天⇄本期 切换且刷新后保持（`niuma.miniView`）；`Esc` 与「回大窗」都能回到大窗；首次进入显示一次 `Win+Ctrl+T 置顶` 提示并在 3 秒后消失、再次进入不显示。

## 9. 不做清单（本版明确排除）

- 不加图表、目标、日历、设置入口（小窗只做"看"+ 最低限度操作）。
- 不做假置顶、不做窗口透明度/无边框（需要 Electron，单文件网页做不到，不做承诺）。
- 不自动开始/自动存档（误记风险大于便利）。
- 不在小窗提供主题切换（主题属于大窗设置）。
- 不改大窗版式与现有快捷键语义。
