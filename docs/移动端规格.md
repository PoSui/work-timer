# 移动端规格 v1

> 适用：牛马计时器所有后续版本。任何改动布局/字号/按钮的版本，验收时必须按本规格过一遍手机档。
> 现状基线：v30.03（`.wrap` max-width 900、`body` padding 26/14/70、`.chips` 三列、顶栏 3 个 `.mini-btn` + 状态徽章，当时无 `@media`）。v30.04 起主数字全档统一为 `clamp(40px,12vw,72px)` 并加手机断点；v30.05 起删除空格提示。以下规格以当前实现为准。

## 1. 断点定义

| 档位 | 宽度 | 设备 | 布局原则 |
|---|---|---|---|
| 手机 | `≤720px` | 320 / 375 / 390 / 430 | 单列为主；隐藏桌面专属功能；触控优先 |
| 平板 | `721–1024px` | iPad 竖屏、折叠屏展开 | 接近桌面，三栏保留，字号降一档 |
| 桌面 | `>1024px` | 现网 900 容器 | 保持 v30.03 现状，不动 |

实现用 `@media (max-width:720px)` 与 `@media (min-width:721px) and (max-width:1024px)`；**优先按「手机档 + 桌面默认」写，平板只做字号/间距微调**，避免三套规则打架。

## 2. 手机档（≤720px）逐区规格

| 区域 | 规格 |
|---|---|
| `body` | `padding:12px 10px 48px`；背景不变 |
| `.wrap` | `max-width:none` |
| 顶栏 `.top` | 单行：品牌靠左（`max-width:58%`，`overflow:hidden;text-overflow:ellipsis;white-space:nowrap`），右侧只留「主题」+「状态」；`.tools{gap:6px}`；`margin-bottom:10px` |
| 品牌 | 12px；窄到 320 可只显示「牛马计时器 · v30.0X」，版本号放 `title` 也行 |
| 状态徽章 | 11px，`padding:3px 9px`，圆点保留 |
| **小窗按钮** | **隐藏**（`#btnMini,#btnBig{display:none}`）；手机不提供小窗模式 |
| 主卡片 `.card` | `padding:16px 14px`，圆角 16 |
| 主数字 `.money` | `font-size:clamp(40px,12vw,72px)`；`white-space:nowrap`；`letter-spacing:-1px`；`font-variant-numeric:tabular-nums`。320px 下 40px，「¥197.04」完整可见（实现值，规格与代码一致） |
| 说明行 `.sub` | 12px、行高 1.5；最多两行，不许溢出 |
| 三栏 `.chips` | `grid-template-columns:repeat(2,1fr);gap:8px`；三张卡按顺序排：本期已赚、距下班各占一格，**时薪卡 `grid-column:1/-1` 独占整行**（`#chipRate`），因文字最长 |
| `.chip` | `padding:10px 10px`；`.k` 11px / `.v` `clamp(15px,4.6vw,19px)`；`.k/.v` 均 `white-space:nowrap`（时薪值允许 15px） |
| 进度条 `.bar-row` | 保留 3 条，`margin-top:12px`；`.bar-top` 11px 单行（`flex-wrap:nowrap`）；`.bar` 高 8px 不变；进度百分比与「还差」必须同行显示，不换行 |
| 按钮 `.btns` | `flex-direction:column;gap:8px`；`button{width:100%;min-height:44px}`；`.b-go` 用整行主色，`min-width:auto`；存档/继续同样整行 |
| 空格提示 `.hint` | **全局不提供**：v30.05 起从 DOM 删除该提示节点（桌面/手机都不显示）；空格快捷键本身保留 |
| 日历 | 7 列压缩：`.cal` 字号 11px，格高 ≥44px（宽度受 7 等分限制，320px 下约 37px，属网格例外）；过去可点格保证 `min-height:44px` |
| 攒钱/对账/时薪轨迹 | 卡片 `padding:14px`；表格/历史条横向不滚动、数字字号降到 12–13px |
| 抽屉 `#sheet` | 宽度 100%，底部圆角；`max-height:86vh`，内部纵向滚动 |
| 菜单 `.menu` | 每项 `min-height:44px`，字号 14px |

## 3. 平板档（721–1024px）

- `body{padding:20px 16px 60px}`；`.wrap` 仍 `max-width:900px`。
- 顶栏保留全部按钮（含小窗）；`.tools{gap:8px}`。
- `.money` 与手机同档 `clamp(40px,12vw,72px)`（v30.04 起全档统一，2026-11-04 回写）；`.chips` 保持 3 列，`gap:10px`。
- 按钮行保持横排，`button{min-height:44px}`；不显示空格提示（`.hint` 全局已移除）。
- 其余沿用桌面值，不做单独重排。

## 4. 桌面档（>1024px）

- `.wrap` 900、三栏、主数字 `clamp(40px,12vw,72px)`（v30.04 起全档统一）、小窗按钮可见；空格快捷键保留，但不再显示 `.hint` 提示节点（v30.05 已从 DOM 删除）。
- 深色/浅色 token 与 v30.03 一致，不允许为了手机改桌面值。

## 5. 触控热区

- 所有可点控件（按钮、`.chip.hit`、`.hit`、菜单项、抽屉按钮、日历过去格）**热区 ≥44×44px CSS 像素**；高度不足时用 padding 补，不要只放大字号。
- 相邻控件间距 ≥8px，防误触。
- 日历 7 列在 320px 下宽度不足 44px，属唯一例外：高度 ≥44px、左右 gap ≥2px，且只对「可点选」的过去工作日加 `touch-action:manipulation`。

## 6. 手机上隐藏/关闭的功能

| 功能 | 处理 |
|---|---|
| 小窗模式（`?mini=1`、`#btnMini`、`#btnBig`） | 手机档隐藏按钮；带 `?mini=1` 打开时**忽略参数、按普通页面渲染**（JS 加 `innerWidth>720` 判断，或 CSS 强制 `.mini` 失效） |
| 空格快捷键提示 `.hint` | **全局不提供**：DOM 中不再渲染该节点；空格快捷键保留，只是不提示 |
| 桌面置顶提示（PowerToys `Win+Ctrl+T`） | 只在桌面显示；手机永远不显示 |
| 悬浮/小窗相关动画 | 手机不加载 |

## 7. 验收标准（3 条，可直接转断言）

1. **无横向溢出**：在 320 / 375 / 720px 宽度下，`document.documentElement.scrollWidth <= window.innerWidth`，且 `.wrap` 的 `getBoundingClientRect().right <= innerWidth`（无元素被裁或撑出屏幕）。
2. **手机布局正确**：`width<=720px` 时 `#btnMini` 计算样式 `display:none`；`.chips` 为 2 列，`#chipRate` 宽度等于 `.chips` 宽度（独占一行）；`.chip .k` 与 `.chip .v` 均单行（`scrollWidth<=clientWidth` 且 `getClientRects().length===1`）。
3. **主数字不裁切且无桌面回退**：320px 下 `#todayEarn` 文本 `¥197.04` 完整（`scrollWidth<=clientWidth`、右边界在卡片内）；>1024px 时 `.chips` 回到 3 列、`#btnMini` 可见，且浅色/深色 token 与 v30.03 一致（对比度断言仍过）。

> **流程（v30.06 起）**：每个版本验收固定加一次 375px 检查——① 首屏「开始上班」在 812px 高度内可见；② `scrollWidth <= innerWidth` 无横向溢出；③ 主数字与金额不被裁。结论写进该版验收报告。
