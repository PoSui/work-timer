## 小窗专项核对（本版核心）

1. **query 解析正确**：`app.v8.js:748` 用 `/(?:^|[?&])mini=1(?:&|$)/.test(String(location.search||""))`，只认独立的 `mini=1`；`?mini=10`、`?nominial=1` 不会误判；`location` 缺失时 try/catch 兜底为 false（Node 测试台里前 47 组没有 `location` 桩也能正常启动）。
2. **只在 `mini=1` 时加类**：全文件 `classList.add("mini")` 仅 1 处（`:751`），且受 `isMini` 保护；无 query 时不会加（harness 第 48 组第 4 条断言验证）。
3. **`.mini` CSS 只依赖现存节点**（逐条核对，全部能在 HTML 找到）：`.wrap`、`.card:not(.main)`、`.card.main`、`.top .brand`、`.money`、`.sub`、`.chips`、`.hint`、`.btns`、`#btnBig`；旧的 `#mainCard/.big/.grid3/.cell/.foot/#miniHint` 已全部移除（`index.html:131-143`）。
4. **「回大窗」出口存在且可用**：`#btnBig` 在 `index.html:195`，默认 `display:none`，`body.mini` 下变 `inline-block`；点击先 `window.close()`，失败/被浏览器拦截时回退 `location.href=location.pathname`（去掉 query 回主视图）——逻辑核对通过；真实弹窗行为需用户真机确认。
5. **新增断言是否真覆盖**：harness 第 48 组 4 条——①`?mini=1` 启动后 `body.mini` 存在 ②CSS 文本里是 `body.mini .card:not(.main)` 且不含 `body.mini #mainCard` ③HTML 有 `btnBig` ④无 query 不加类。①②③④均针对本版改动，**不是空跑**；弱点见 P3-1。
