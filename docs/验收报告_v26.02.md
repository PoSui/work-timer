## 发现的问题（按严重度排序）

**P1 阻断：无。** 本版只改版本文本与 README，没有触碰任何业务逻辑；157 = 154 + 3，无旧断言删除；idb 15 条未变。

**P2：无。**

**P3 建议：**

1. README 的**测试徽标仍写 155**（`README.md:7`），实际为 harness 157 + idb 15。版本徽标已收口，测试数没跟上；建议改成「172 passed」或改为指向 CI。
2. README 的 v26 行写「**向导必弹**」，与实际相反：v26/v26.01/v26.02 首开**不弹**空向导，只有薪资/工时缺失时才弹（v27 验收重点①）。公开 README 会让人误解首开行为，建议改成「首开不再弹空向导；缺薪资时必弹」。
3. 一致性断言只覆盖 title/brand/README 行，**没覆盖 README 徽标与测试数**；建议至少断言徽标含 `v26.02`，测试数可人工更新。
4. 既有小问题（非本版引入）：`ids.json` 仍有 7 个悬空 id（`detailBody/mMode/rankBody/rankTag/rankWrap/setupMsg/sumTag`），测试台靠第 47/48 组读真实 HTML 兜底；备份 JSON 的 `ver` 仍硬编码 `"v21"`；目标改金额/排序/✅ 与「本期构成合计 = 本期已赚」仍无断言（建议补 3–4 条）。
5. 小窗内「小窗」按钮未隐藏（`body.mini` 只隐藏 brand），点击会重载同一 mini 窗口，属轻微冗余；建议 `body.mini #btnMini{display:none}`（v26.01 报告已提，未阻断）。
